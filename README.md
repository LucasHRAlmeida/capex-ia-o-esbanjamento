# capex-ia-o-esbanjamento

**Manifesto:** o capex de IA não se sustenta. Matemática do esbanjamento, cinco escolas adversariais, e a tese de que o valor real está no corpus — sem corpora não existem pesos.

## A página

Abra [index.html](index.html) no navegador. É client-side: quatro gráficos (Chart.js), tabela ano a ano, as cinco escolas com veredito, e um simulador de ROI que recalcula em tempo real.

## A tese, em uma frase

> O que importa é a tecnologia **necessária**, o suficiente — não o exagero. Sem corpora não existem pesos.

## Os números (cenário base, US$ bi)

| | |
|---|---|
| Capex total 2023–2030 | 3.805 |
| Receita total | 755 |
| Gap acumulado | 3.050 |
| ROI acumulado em 2030 | 19,8% |
| Depreciação 2030 vs receita | 400 bi vs 260 bi |

Para fechar o gap em 2030, a receita precisaria ser **2,69×** a projetada — ~18 bilhões de assinantes pagando como Netflix.

## Estrutura

- `index.html` — a página completa (manifesto assinado + dados + gráficos + simulador)
